# Stempeluhr

Persönliche Zeiterfassung als Web-App (PWA) für Android/Chrome – stempeln per NFC-Chip, nach dem Vorbild klassischer Zeiterfassungsterminals.

**App öffnen:** https://flpt85.github.io/stempeluhr/

- Kommen, Gehen, Pause, Dienstgang, Kontenauskunft
- Gleitzeit- und Urlaubskonto, Fehlzeiten mit Anträgen, Feiertage Bayern
- Pausenregeln nach Arbeitszeitgesetz
- Export als CSV und PDF-Monatsnachweis

Alle Buchungen bleiben ausschließlich auf dem jeweiligen Gerät gespeichert.
